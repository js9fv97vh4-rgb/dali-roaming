# 云南漫游 · 大理首站 · V1.1.0

从云南地图上的一颗红星出发，走进不同目的地的山水与地方文化。当前开放第一站：大理洱海。

本次更新：站点展示名改为「云南漫游」，云南首页使用通用地图视觉；扎染纹样限定在大理页面。项目目录、仓库名和原有浏览器行程键保持兼容。

**[在线体验](https://js9fv97vh4-rgb.github.io/dali-roaming/)** · **[下载 V1](https://github.com/js9fv97vh4-rgb/dali-roaming/releases/tag/v1.0.0)**

## 一镜漫游

首页点击「一镜走进大理」，或在洱海页选择「播放山海长卷」，即可体验 3D 运镜与真实照片同步的旅程。支持暂停、拖动进度、跳站与整段收藏；「我的行程 → 播放我的旅程」按自己保存的顺序播放。

内置「风从洱海来」「把时光染成蓝」「半日，留给湖岸」三条编辑路线。日光与暮色为艺术化演绎，照片保留各自拍摄语境，不代表连续实拍或实时光照。停留时间为规划参考，不包含交通、排队与用餐。

景点与照片可通过浏览器地址分享，刷新恢复当前页面，返回键逐层退出。扎染可选择九个扎结位置，完成后保存原创 SVG 灵感纹样。上述交互仍可静态托管，不需要账号或新增服务。

## 当前版本包含什么

本地新增：地图加载时先显示约 90 KB 的真实三维预览图，配合分阶段进度与剩余时间估算；机场、高铁站和自驾入口加入程序生成的立体示意模型。只有进入洱海时才加载三维引擎。

- 云南 16 州市分区地图，点选地名查看全称；轻微云影与风纹支持暂停，点击大理红星进入洱海。其他目的地尚未开放。
- 苍山洱海 3D 地形地图：拖动旋转、缩放、四种预设视角，完整衔接全景照片和渔灯夜色。
- 机场、大理站、自驾示例入口；海西、海东与全部景点筛选。
- 15 处景点、全景照片地图、主图艺术字、多图相册与完整照片查看。
- 目的地与停留点选择、沿岸候选、行程排序、文字复制与下载。
- 放大洱海的渔灯模式：灯影漂动、水面风纹、动画暂停，搭配 4 张洱海渔灯实景资料图。
- 靛蓝扎染视觉，以及“绞扎 → 浸染 → 拆线”的互动示意。
- 适配手机，支持键盘与减少动态效果偏好。

行程保存在**当前浏览器**，刷新后可恢复；不需要账号或后端，不会跨设备同步。地图连线表示探索顺序与沿岸方向，不能替代道路导航。

## 启动

需要 Node.js 20 或更新版本；生成 ZIP 发行包另外需要 Python 3。

**macOS 本地打开：双击项目根目录的 `启动云南漫游.command`。** 它会核对正在运行的预览是否属于此文件夹，自动启动或复用正确的服务，再打开浏览器。新启动服务时请保留终端窗口；关闭后再次双击即可重新启动。也可以运行 `npm run open`。

双击根目录或 `web/` 中的 `index.html` 会显示启动指引，避免浏览器通过 `file://` 打开时将 3D 地图降级为平面备用地图。完整本地体验请使用启动程序打开的 `http://127.0.0.1:8765/` 地址。GitHub Pages 上的根目录入口仍会进入正式网页并保留目的地锚点。

```sh
git clone https://github.com/js9fv97vh4-rgb/dali-roaming.git
cd dali-roaming
npm run dev
```

打开 `http://localhost:8765`。静态网页启动不需要安装第三方依赖。端口被占用时：

```sh
npm run dev -- --port 8766
```

检查、构建和封装：

```sh
npm test
npm run build
npm run preview
npm run package
```

`build` 输出 `dist/client` 静态网站；`package` 输出 `release/dali-roaming-v1.1.0.zip` 和 SHA-256 校验文件，包含源码与静态网页。下载解压后使用 `npm run open` 或 `npm run dev` 启动。3D 地图通过本地模块和地形文件加载，需要 HTTP 服务。

如需修改可选数据库模型，再执行 `npm ci` 安装锁定的依赖。

## 部署到 GitHub Pages

在仓库 **Settings → Pages** 选择 **Deploy from a branch → main → /(root)** 并保存。根目录入口会进入 `web/index.html`，保留访问时的页面锚点；`.nojekyll` 让静态资源直接发布。无需数据库、密钥或付费服务。

其他静态托管服务可直接发布 `web/` 或 `dist/client/`，使用相对资源路径。

逐图来源、分发范围和拍摄信息见 [素材说明](docs/ASSETS.md)、[第三方授权](THIRD_PARTY_NOTICES.md) 与 [素材清单](asset-sources.json)。

## 项目结构

```text
web/                 网页、地图、景点、相册和图片
data/                可复用地图几何与点位数据
scripts/             本地预览、构建与打包
tests/               地形投影、行程模型、素材完整性、可选存储测试
worker/              原站点的可选 Sites 存储参考实现
db/、drizzle/        可选数据库模型与空库迁移
asset-sources.json   分发照片与外部引用的作者、来源和授权
docs/                素材规则、3D 地图与存储说明
```

GitHub Pages 仅发布静态页面；`worker/` 不会执行，也不是独立的通用认证服务。可选存储的适用范围见 [存储说明](docs/STORAGE.md)。包中没有原站点绑定、个人行程、密钥或原 Git 历史。
