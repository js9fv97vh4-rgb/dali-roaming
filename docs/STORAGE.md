# 行程保存

公开网页默认只使用 `localStorage`，键名为 `dali-roaming:journey:v1`。保存入口、游览区域、选中景点、目的地与停留点。用户可以复制/下载行程；清除浏览器站点数据后，本地行程会消失。不同浏览器和设备不共享这些数据。浏览器拒绝存储时，页面会提示并仍允许导出。

`worker/index.js` 与数据库模型保留为原 Sites 环境的参考实现，**未接入公开静态网页**。

该 Worker 依赖上游受信任的身份网关注入 `oai-authenticated-user-id`，并删除访问者伪造的同名请求头。普通公网客户端可以自行构造请求头，这个字段本身不是身份验证。不能把此 Worker 当作通用登录服务直接开放。

参考实现默认关闭存储接口。仅当入口已经部署可信身份网关、阻断绕过网关的直连请求，并设置 `TRUSTED_IDENTITY_GATEWAY=sites` 时，才允许进入存储逻辑。这个开关本身不会提供认证。若为其他托管环境添加后端，先实现真实的认证与授权，再接入数据库。

`scripts/build.mjs` 生成的可选 Worker 配置只包含示例数据库名和全零占位 ID，没有原站点数据库标识或用户数据。GitHub Pages 不运行 Worker。
