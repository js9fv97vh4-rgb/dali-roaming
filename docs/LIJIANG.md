# 丽江目的地

入口 `#lijiang`；景点直达 `#lijiang?spot=baisha`；照片直达 `#lijiang?spot=lugu&frame=1`。云南首页山水徽记、首页目的地链接和顶部导航都可进入。

首批范围固定为十处：丽江古城（大研）、束河古镇、白沙古镇、玉龙雪山、蓝月谷、云杉坪、牦牛坪、拉市海、泸沽湖、程海。泸沽湖与程海使用独立视角，主题筛选不是一日游路线。

## 数据与交互

- `web/lijiang-data.js`：十处景点、逐图观看文字、实景照片与逐图署名。
- `web/lijiang.js` / `web/lijiang.css`：主题筛选、地图选点、可关闭景点卡片、独立本地收藏、相册与分享链接。
- `web/paper-map.js` / `web/paper-map.css`：本地 SVG 地图、连续青绿山水插画与静态浅雾青纸面。丽江主图与两个湖区小图使用SVG，无三维引擎、无地图服务。
- `web/view-routes.js` / `web/app.js`：共同处理云南、大理、丽江路由与弹窗；丽江使用 spot/frame，不与大理 scene/photo 混用。
- 收藏键 `yunnan-lijiang-saved-v1`，只保存当前浏览器，不改动大理行程或调用其存储接口。浏览器禁用存储时，选择在本次会话保留并提示。

## 地图与照片边界

丽江地图采用三个北向上的二维图幅：雪山古镇主图8处、泸沽湖1处、程海1处。各图幅独立比例，点位沿用来源可核查的WGS84坐标；地标插画是艺术化示意，标签通过引线指向实际位置，不绘制虚构道路。湖岸及岛屿沿用 OSM 数据，保留 ODbL 署名。玉龙雪山点位代表主峰，不是游客入口，湖心点不代表码头。

不再加载丽江DEM、Three.js、旧三维截图。地图在WebGL不可用时仍可操作；湖岸数据失败时保留点位和实景入口，并明确提示轮廓暂未加载。

随包照片为有开放许可的实拍，许可与来源记录在 `asset-sources.json`、`THIRD_PARTY_NOTICES.md`。丽江网近期照片为源站引用，未随代码分发。外链无法加载时明确提示，并提供原作链接，不用其他景点照片替代。

文化资料：[UNESCO 丽江古城](https://whc.unesco.org/en/list/811/)。拉市海游览提示参考[保护区通告](https://www.lijiang.cn/news/shengtai/article/181655.html)。不编造活动时间、票价或实时开放状态。

## 检查

运行 `npm test`、`npm run build`。浏览器验证应覆盖云南→丽江→大理、十处景点、三个地图图幅、收藏刷新、相册下一张与关闭、外部直达、手机390px，以及湖岸数据失败的可用性。三维截图使用软件渲染检查时，其速度不代表真实设备性能。

公开版本通过 GitHub 仓库同步；预览与生产均使用同一套静态页面。
