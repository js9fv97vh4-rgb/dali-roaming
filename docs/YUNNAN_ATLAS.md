# 云南州、市探索地图

2026-11-09：十六州市地名位于地图两侧的留白，不再叠加方块底色。细弧线箭头连接各地名与区域内部锚点；大理、丽江使用朱红题签和“进入漫游”提示，整块为原生链接。

## 数据与投影

- 州、市现用名称：云南省民政厅[行政区划设置名录](https://ynmz.yn.gov.cn/bmfw/xzqh/xzqhsz/)，2026-10-16 核对，共 8 个地级市、8 个自治州。
- 分区形状：© OpenStreetMap contributors / Wambacher，通过 [geoBoundaries 3.0.0 中国 ADM2 档案](https://www.geoboundaries.org/data/geoBoundaries-3_0_0/CHN/ADM2/)取得，ODbL 1.0。档案标注边界年份为 2017、更新日期为 2020-05-25。数据只用于区域探索示意，不声称是现行法定界线。
- 省级轮廓继续使用 Natural Earth 公有领域数据。所有分区采用与原省级轮廓相同的经纬度线性投影，并裁切至该轮廓。
- 先统一简化共享弧，再组装多边形，避免各区独立简化产生裂缝。保留地理坐标的子集位于 `data/yunnan-prefectures.geojson`；网页 SVG 路径位于 `web/prefecture-data.js`。
- 标签锚点以区内点计算；地名移到画外两侧留白，细弧线箭头末端仍指向原有区内点，不改变地图地理形状。

从原始档案重新生成数据，在项目根目录运行：

```sh
python3 scripts/prepare-prefectures.py /path/to/geoBoundaries-3_0_0-CHN-ADM2.topojson
```

## 入口与交互

- 大理、丽江的地名题签、地图分区、下方目录都直接进入对应目的地；使用原生链接，支持键盘 Enter、浏览器返回与在新标签打开。
- 其余十四个地名点选后更新地图提示与下方地区说明，明确尚未开放；Enter / Space 同样可选择。
- 地名、区域和引线同步高亮，装饰与引线不拦截点击。普通地名仅有透明点击范围，获得键盘焦点时出现细虚线提示。
- 桌面使用两列各八项，手机加大行距与字级；390px 下所有题签点击范围均至少44px，无重叠。
- 放大后可拖动和用方向键移动，Escape/全图恢复。拖动结束产生的延迟点击会被拦截，下一次正常点击和键盘激活继续有效。
- 保留本地山水插画、地区几何与来源署名，没有新增持续动画或外部地图服务。

## 验证

本轮浏览器检查1440、874、820、390px布局，两入口点击/键盘/返回、未开放地区选择、地图分区入口、目录入口与拖动防误触。自动测试覆盖视图边界、屏幕尺寸变化和拖动后点击处理。截图及检查结果保存在本机会话可视化目录的 `map-entries-20261109/`。
